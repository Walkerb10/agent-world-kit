The core idea

An agent = a body + a brain, bridged by a loop.

A real look inside

This is the perception function. It's in the kit verbatim.

No watered-down "example." What's below is the code that gives the agents eyes — exactly as it ships:

javascript · senses(bot) 
const found = bot.findBlocks({ matching: built, maxDistance: 48, count: 120 })
if (found.length > 6) lines.push(`A structure of ~${found.length} placed blocks is nearby.`)

for (const e of Object.values(bot.entities))
  if (e.type === 'player' && e.username && e.position.distanceTo(pos) < 32)
    lines.push(`${e.username} is ${R(e.position.distanceTo(pos))}m away.`)

return '[WHAT YOU SEE:\n- ' + lines.join('\n- ') + ']'

Inject that into every prompt and the agent can say "I'm in a savanna, your glass platform is 10 blocks north." That one shift is the difference between a chatbot and an agent.
